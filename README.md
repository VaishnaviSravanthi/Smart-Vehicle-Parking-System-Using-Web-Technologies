# Smart-Vehicle-Parking-System-Using-Web-Technologies
Smart Vehicle Parking System Using Web Technologies

README

Overview

The Smart Vehicle Parking System is a web-based application developed using Python (Django) to simplify parking management. It enables users to check parking slot availability, book slots online, and manage bookings efficiently. The system provides an admin panel to monitor parking spaces, users, and booking records in real time.

Features

- User Registration and Login
- Secure Authentication
- Real-Time Parking Slot Availability
- Online Parking Slot Booking
- Booking History
- Admin Dashboard
- Parking Slot Management
- User Management
- Payment Simulation
- Responsive Web Interface

Technology Stack

- Backend: Python, Django
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Database: SQLite
- ORM: Django ORM
- Version Control: Git

System Requirements

- Python 3.10 or above
- Django 4.x
- SQLite
- Git
- Web Browser (Chrome, Edge, Firefox)

Installation

1. Clone the repository:
   git clone https://github.com/yourusername/smart-vehicle-parking-system.git
2. Navigate to the project folder:
   cd smart-vehicle-parking-system
3. Create a virtual environment:
   python -m venv venv
4. Activate the virtual environment.
5. Install dependencies:
   pip install -r requirements.txt
6. Apply database migrations:
   python manage.py migrate
7. Create an admin account:
   python manage.py createsuperuser
8. Start the server:
   python manage.py runserver
9. Open your browser and visit:
   http://127.0.0.1:8000/
